# Meter Down FM

A single-page ambient radio concept for Delhi auto-rickshaw drivers, built with Next.js, TypeScript, and CSS.

## Run locally

```bash
npm install
npm run dev
```

## Placeholder assets

- `public/hero-auto.png` is generated concept artwork and should be replaced with final licensed artwork before launch.
- Track names and artists in `lib/tracks.ts` are fictional.
- Audio URLs point to public SoundHelix demo files. Replace them with audio you own or are licensed to stream.
- Spotify and YouTube Music links currently open the platform homepages; replace them with the station playlists when available.
